# Portfolio

Short, interviewer-friendly engineering case studies will live here. Each one will link to original source code, design files, test evidence, and engineering decisions under `projects/`.

**Planned case studies:** FIELDLINK bidirectional UART/LoRa verification; protocol adapter interoperability and normalized diagnostics; reproducible fault-injection and measurement workflows; closed-loop control and later custom-PCB integration.

A strong case study should show the requirement, design choice, implementation, as-tested configuration, raw evidence, failure investigation, and what changed after testing. The goal is to demonstrate engineering reasoning, embedded C/C++ ability, test methods, and maintainability—not simply a list of features. Existing standards such as MAVLink and Modbus are integration opportunities, not competitors that must be outperformed.

Only describe results as verified when supported by actual tests.
